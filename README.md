
# Power BI Sales Analysis Dashboard

##  Project Overview

This project is an interactive **Power BI Sales Analysis Dashboard** developed to analyze sales performance and generate meaningful business insights.

The project combines **SQL and Power BI** to work with sales data, analyze key metrics, and present the results through interactive visualizations.

##  Objectives

- Analyze overall sales performance
- Identify sales trends and patterns
- Monitor important sales KPIs
- Analyze regional sales performance
- Create interactive reports for business analysis
- Present data in an easy-to-understand visual format

## 🛠️ Tools & Technologies

- **Power BI**
- **SQL**
- **Power Query**
- **DAX**
- **Data Visualization**
- **Data Analysis**

##  Project Workflow

1. Collected and prepared the sales data
2. Used SQL for data analysis and querying
3. Imported the required data into Power BI
4. Cleaned and transformed the data using Power Query
5. Created relationships between relevant tables
6. Created calculated measures using DAX
7. Designed interactive dashboards and visualizations
8. Added filters and slicers for interactive analysis
9. Analyzed the final dashboard to identify sales insights

##  Dashboard Features

The dashboard provides analysis of:

- Sales performance
- Sales trends
- Regional performance
- Key Performance Indicators (KPIs)
- Interactive filtering
- Detailed sales analysis
